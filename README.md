# Substack Likes Search

Substackで「いいね」「保存（あとで読む）」した記事を、**タイトル・著者・本文から横断検索**できるChrome拡張機能です。
Substackのいいね一覧・保存一覧は検索ができないため、「あの記事どこでいいねしたっけ?」を解決します。

> **v1.1の新機能**：保存（あとで読む）した記事も同期対象になりました。「すべて / ♥いいね / 🔖保存」のタブで絞り込みできます。

---

## 利用方法（ユーザー向け）

### 1. インストール

- **Chrome Web Storeから**（公開後）：ストアで「Substack Likes Search」を追加
- **開発版を読み込む場合**：
  1. `chrome://extensions` を開く
  2. 右上の「デベロッパーモード」をオン
  3. 「パッケージ化されていない拡張機能を読み込む」→ このフォルダを選択

### 2. 初回の取り込み

1. **Substackにログイン**した状態にする
2. ツールバーの拡張アイコン（虫眼鏡＋ハート）をクリック
3. 検索画面が新しいタブで開く
4. 自動であなたのユーザーIDを検出し、いいね一覧の取り込みを開始
   - 初回は本文もまとめて取得するため、いいね件数によっては数分かかります
   - 「本文を取得中… ○/○」と進捗が出ます

### 3. 検索する

- 検索ボックスにキーワードを入力するだけ
- **スペース区切りで複数語のAND検索**（例：`育児 AI` → 両方を含む記事）
- 「すべて / ♥いいね / 🔖保存」のタブで種別を絞り込めます
- ヒットした本文箇所が抜き出され、検索語がハイライト表示されます
- 記事をクリックすると元のページが開きます

### 4. 2回目以降

- アイコンをクリックして開くと、**自動で差分同期**が走ります
- 前回以降に新しくいいねした記事だけを取り込むので、数秒で終わります
- 「新着 ○件を追加しました」または「最新の状態です」と表示されます

## 設定（⚙ボタン）

| 項目 | 説明 |
|---|---|
| IDを自動検出 | ユーザーIDを自動で取得し直します（通常は自動なので不要） |
| ユーザーID手動入力 | 自動検出できない場合に、数字IDを直接入力 |
| データを全消去 | 保存済みのID・いいねデータをすべて削除（リセット） |

## よくある質問

**Q. 同期は毎回押す必要がありますか?**
A. いいえ。検索はいつでも一瞬です。同期はアプリを開いたときに自動で走ります。

**Q. ノート（短文投稿）も検索できますか?**
A. いいえ。記事（Post）のみが対象です。

**Q. データはどこに保存されますか?**
A. お使いのブラウザ内（chrome.storage.local）だけです。外部には一切送信されません。

**Q. 同期が「いいね一覧を取得中…」で止まります**
A. Substackにログインしているか確認してください。ログイン状態を使ってデータを取得します。

## 技術メモ（開発者向け）

- Manifest V3。`background.js`（service worker）から `substack.com` のAPIを直接fetch（`host_permissions`によりログインCookieが送られる）。
- ユーザーIDは `substack.com/home` のHTMLに含まれる `primary_user_id` から自動取得。
- いいね一覧：`/api/v1/reader/feed/profile/{userId}?types[]=like`（nextCursorでページング）。
- 保存一覧：`/api/v1/reader/saved`（要ログインCookie・nextCursorでページング）。
- ロジックのテスト：`node test_logic.js`（chrome API・fetchをスタブしてネットワーク不要で実行）。
- 本文：各記事の `{subdomain}.substack.com/api/v1/posts/{slug}` の `body_html`。
- 検索UIはポップアップではなく**タブ**で開く（一部環境でポップアップにIMEフォーカスが当たらないため）。
- 非公式APIに依存しているため、Substackの仕様変更で動作しなくなる可能性があります。
